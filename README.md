# 工具箱 Toolbox

Windows 10/11 桌面工具集，iOS 氣泡風格介面。左下角齒輪可切換文字大小（小／中／大）與深淺色。

## 下載

到 [Releases](../../releases/tag/v1.0.0) 下載 `Toolbox.exe`，免安裝直接執行。
版本號固定為 `1.0.0`，每次更新都會覆蓋同一個 Release。

> - 程式會要求**系統管理員權限**（讓按鍵監聽在遊戲中生效），每次開啟會出現 UAC 確認。
> - 執行檔未簽章，第一次執行若出現 SmartScreen 警告，請點「其他資訊」→「仍要執行」。

## 楓之谷工具

### 計時器

- 預設三項：輪迴碑石 9:50、燃燒戒指 15:05、靈魂亞努斯 2:00（冷卻 50 秒），可新增自訂計時器。
- **重新計時方式**
  - 一般：時間到通知後停止。
  - 次數：自動重複設定的次數（0 = 無限）。
  - 指派按鍵：時間到後進入超時向上計時，按下指派按鍵才重新計時；可開啟「超逾回補」。
- **指派按鍵**：可指派多個，支援組合鍵（如 `Ctrl+S`）與滑鼠側鍵。點已指派的按鍵後按 Esc 可取消該指派。
- **冷卻時間**：重新計時後的冷卻期間，按鍵無效。
- **通知**：短＝一次；長＝每 3 秒重複直到重新計時（沒有指派按鍵時只通知一聲）。
  音效可選內建三種提示音、Windows 語音唸出名稱，或自訂音效檔（wav/mp3/ogg/flac）。
- **浮動視窗**：每個計時器一個，可調透明度。解除鎖定可拖曳、拉右下角縮放；鎖定後滑鼠穿透，不擋遊戲。
  只支援視窗化或無邊框全螢幕。
- **只在新楓之谷時運作**：切到其他視窗時繼續倒數，但暫停監聽按鍵並隱藏已鎖定的浮動視窗。
  以執行檔名稱含 `MapleStory` 或視窗標題含「楓之谷」判斷；上方會顯示目前偵測到的前景程式。

## 工具箱

### 序號複製

左邊貼上文字並擷取，右邊顯示序號清單（清單獨立捲動）。擷取後自動切換即開啟：
在其他程式按 **Ctrl+V** 貼上後，剪貼簿自動換成下一組。

- 規則：15–25 碼英數字，排除純數字，自動去除重複。
- 只有剪貼簿仍是目前序號時才切換；右鍵貼上無法偵測，可用「下一組」或點清單跳轉。

## 資料保存

所有設定與進度存在 `%APPDATA%\com.toolbox.desktop\`（`state.json`、`timers.json`），
包含視窗大小、主題、字體、序號進度與計時器設定。

## 開發

技術棧：[Tauri 2](https://tauri.app)（Rust 後端 + 原生 HTML/CSS/JS 前端）

```bash
npm install
npm run dev     # 開發模式
npm run build   # 輸出 src-tauri/target/release/toolbox.exe
```

推送到 `main` 時，GitHub Actions 會在 Windows 上編譯，並刪除重建 `v1.0.0` Release。
