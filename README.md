# 工具箱 Toolbox

Windows 10/11 桌面工具集，iOS 氣泡風格介面，支援深色／淺色模式與小／中／大字體。

## 下載

到 [Releases](../../releases/tag/v1.0.0) 下載 `Toolbox.exe`，免安裝直接執行。
版本號固定為 `1.0.0`，每次更新都會覆蓋同一個 Release。

> 執行檔未簽章，第一次執行若出現 SmartScreen 警告，請點「其他資訊」→「仍要執行」。

## 功能

### 序號複製工具

1. 把含有序號、時間戳記、道具名稱等的混雜文字貼進輸入框，按「擷取序號」。
   - 規則：15–25 碼英數字（不分大小寫），排除純數字，自動去除重複。
   - 只擷取完整片段，例如 30 碼的長字串不會被切出前 25 碼。
2. 開啟「自動切換」，目前序號會放進剪貼簿。
3. 到其他程式按 **Ctrl+V** 貼上，約 0.15 秒後剪貼簿自動換成下一組，清單同步標示進度。
   - 只有當剪貼簿內容仍是目前序號時才會切換；若你另外複製了別的東西，就不會誤跳。
   - 在本程式視窗內按 Ctrl+V 不會觸發。
   - 右鍵選單的「貼上」無法偵測，可用「下一組」按鈕手動切換，或點清單任一組直接跳過去。
4. 全部用完會顯示「已全部使用完畢」。貼上新文字重新擷取時，會取代舊清單並從第一組開始。

序號清單、目前進度、輸入文字、主題與字體設定都會保存在
`%APPDATA%\com.toolbox.desktop\state.json`，重新開啟程式時會自動還原。

## 開發

技術棧：[Tauri 2](https://tauri.app)（Rust 後端 + 原生 HTML/CSS/JS 前端）

```bash
npm install
npm run dev     # 開發模式
npm run build   # 輸出 src-tauri/target/release/toolbox.exe
```

推送到 `main` 時，GitHub Actions 會在 Windows 上編譯，並刪除重建 `v1.0.0` Release。
