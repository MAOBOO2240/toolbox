# 工具箱 Toolbox

Windows 10/11 桌面工具集，iOS 氣泡風格介面。左下角齒輪可切換文字大小（小／中／大）與深淺色。

## 下載

到 [Releases](../../releases/tag/v1.0.0) 下載 `Toolbox.exe`，免安裝直接執行。
版本號固定為 `1.0.0`，每次更新都會覆蓋同一個 Release。

> - 程式會要求**系統管理員權限**（讓按鍵監聽在遊戲中生效），每次開啟會出現 UAC 確認。
> - 執行檔未簽章，第一次執行若出現 SmartScreen 警告，請點「其他資訊」→「仍要執行」。

## 楓之谷工具

### 計時器

- 預設三項：輪迴碑石 9:50、燃燒戒指 15:05、靈魂亞努斯 2:00（CD 50 秒），可新增自訂計時器。
- **直接修改**：點計時器數字即可改時間（倒數中也可改）；數字右邊的 `CD` 可直接改冷卻秒數。
- **重新計時方式**（每個計時器各自設定）
  - 一般：時間到通知後停止，按「開始」可再次計時。
  - 次數：自動重複設定的次數（0 = 無限）。
  - 指派按鍵：時間到後進入超時向上計時，按下指派按鍵才重新計時；可開啟「超逾回補」。
- **指派按鍵**（只在「指派按鍵」模式顯示與生效）：可指派多個，支援組合鍵（如 `Ctrl+S`）、單一修飾鍵與滑鼠側鍵／中鍵。
  點已指派的按鍵後按 Esc 可取消該指派。上方「最後按鍵」可確認全域監聽是否有收到按鍵。
- **左下角總開關**：「全部關閉」只暫停原本有開啟的計時器並隱藏浮動視窗，再按「全部開啟」會恢復原狀。
- **設定（全局）**：通知方式（短／長）、音效（柔和木琴、柔和鐘聲、溫和雙音、語音唸名稱、自訂音效檔）、
  音量 0–200%（每 1% 調整，可點數字直接輸入），以及浮動視窗的顯示、鎖定、透明度（只影響底色，文字永遠不透明）。所有調整都即時生效。
- **浮動視窗**：一個視窗列出正在倒數或超時的計時器，沒有計時器在計時就自動隱藏；名稱太長時視窗自動加寬；顯示開關每次開啟程式預設關閉。解除鎖定可拖曳、拉右下角縮放；鎖定後滑鼠穿透，不擋遊戲。
  只支援視窗化或無邊框全螢幕。
- **只在新楓之谷時運作**：切到遊戲與本程式以外的視窗時繼續倒數，但暫停監聽按鍵並隱藏浮動視窗。
  以執行檔名稱含 `MapleStory` 或視窗標題含「楓之谷」判斷；上方會顯示目前偵測到的前景程式。

### 黃金蘋果轉蛋模擬器

- **獎池**：黃金蘋果／幸運的銀色箱子／幸運的金色箱子三個分頁。貼上文字會依「幸運的銀色箱子」「幸運的金色箱子」標題自動分割，
  每行取最後一個百分比為機率（名稱含 % 也能正確解析）。機率不足 100% 時最下方顯示「請檢查道具機率」補足列。
- **價值**：同名道具在各分頁共用價值。「自動帶入價格」依每抽獲得機率非線性估算（越稀有越高），
  整體縮放成「單抽綜合期望值 ≈ 每抽花費」作為基準；機率 > 30% 與垃圾道具清單內的道具留空（計為 0）。
- **模擬**：1／10／100／1000 抽，每抽必得 1 個碎片；30 碎片開銀箱、100 碎片開金箱。
  道具列的「抽」會一直抽到該道具為止（箱子道具會自動抽蘋果湊碎片再開箱）。
- **獲得道具**：依獎池順序排列，最上方「本次中獎」顯示最近一次的結果，下一次抽獎時併入下方清單。
- **分析**：道具期望值、碎片期望值、綜合 EV、單抽 CP 值、單抽賺錢機率、實際回收率，並由內建評語庫產生 AI 評語。
- 所有獎池、價值、設定與統計都會保存，可隨時「重置統計」。

## 工具箱

### 序號複製

左邊貼上文字並擷取，右邊顯示序號清單（清單獨立捲動）。打開序號複製或擷取後，
自動切換即開啟：在其他程式按 **Ctrl+V** 貼上後，剪貼簿自動換成下一組。
離開序號複製（回到主頁或切到其他工具）時，自動切換會關閉。

- 擷取規則：15–25 碼英數字，排除純數字，自動去除重複。
- 只有剪貼簿仍是目前序號時才切換；右鍵貼上無法偵測，可用「下一組」或點清單跳轉。

## 資料保存

所有設定與進度存在 `%APPDATA%\com.toolbox.desktop\`（`state.json`、`timers.json`），
包含視窗大小、主題、字體、序號進度與計時器設定。

## 開發

技術棧：[Tauri 2](https://tauri.app)（Rust 後端 + 原生 HTML/CSS/JS 前端）

```bash
npm install
npm run dev     # 開發模式
npm run build   # 輸出 src-tauri/target/release/toolbox.exe
```

推送到 `main` 時，GitHub Actions 會在 Windows 上編譯，並刪除重建 `v1.0.0` Release。
