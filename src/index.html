    文字解析

    貼上網頁上的機率文字，可以同時包含黃金蘋果、幸運的銀色箱子、幸運的金色箱子。會依「幸運的銀色箱子」「幸運的金色箱子」標題自動分到三個獎池，並取代原本的道具。

    大獎分界

    黃金蘋果獎池中，排在這個道具上面的道具算大獎（不含這個道具本身）：自動帶入時依稀有度給價，抽到時以金色顯示。這個道具與下面的道具若不在垃圾清單，自動帶入價格為 10。

    Discord 通知

    1. 在 Discord 建一個自己的伺服器（左邊「＋」→ 自己建立 → 僅供我和我的朋友使用）。
    2. 在要收通知的頻道按齒輪「編輯頻道」→「整合」→「Webhook」→「新 Webhook」→「複製 Webhook 網址」，貼到上面。
    3. 使用者設定（左下齒輪）→「進階」→ 打開「開發者模式」。
    4. 在自己的頭像上按右鍵 →「複製使用者 ID」，貼到上面，再按「測試」。

    Windows 開著「勿擾模式」時，Windows 通知只會進通知中心、不會跳出來。Discord 送不出去時（例如沒有網路），會改用 Windows 通知。
